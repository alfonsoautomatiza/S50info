Consulta, exporta y automatiza SAGE50 desde una sola consola.

S50Info es una herramienta gratuita para equipos técnicos que necesitan revisar datos, generar salidas y ejecutar mantenimientos sin abrir SSMS para cada comprobación.

Salida

#clientes se resuelve contra tablas de gestión.

--sqlyear @ une los ejercicios disponibles.

clientes.xlsx queda listo para revisión o entrega.

El valor está en el contexto SAGE50, no solo en ejecutar SQL.

S50Info traduce la forma en que un técnico piensa una consulta SAGE50 a las bases reales, años fiscales y comunes configurados.

Consulta que escribe el técnico SELECT CODIGO, MAX(NOMBRE) FROM #clientes
→
Contexto que resuelve S50Info
  • `#clientes` apunta a tablas de gestión.
  • `--sqlyear @` recorre ejercicios disponibles.
  • `--groupby CODIGO` consolida registros repetidos.

Cinco comandos para el trabajo técnico diario.

Todo queda en una CLI auto-documentada, apta para soporte, integraciones, PowerShell, `.bat` y tareas programadas.

s50info info

Muestra servidor, comunes, años disponibles y estado de conexión.

s50info sql "SELECT * FROM #clientes"

Ejecuta SQL de lectura y muestra el resultado en consola.

s50info export "SELECT * FROM #articulos" --formato xlsx

Genera archivos TXT, CSV, JSON, XML o XLSX; también puede comprimir con `--zip`.

s50info run script\mi_script.py

Ejecuta Python con `proceso`, `query_to_dict` y helpers SAGE50 ya preparados.

s50info reset

Trunca logs técnicos de SAGE50 cuando el mantenimiento lo requiere.

Runbook de exportación programada 
@echo off
s50info export "SELECT * FROM #articulos" --formato csv --output articulos_diarios
if errorlevel 1 exit /b 1

Preparado para automatizar, no para impresionar con pantallas.

La herramienta se distribuye como ejecutable Windows autónomo con PyInstaller. No exige instalar Python en el puesto final: se configura `config.ini`, se verifica con `s50info.exe info` y se integra en los flujos técnicos existentes.

Actualizaciones y releases: el proyecto incluye flujo de ZIP, manifest firmado, GitHub Releases y publicación de documentación para distribuir versiones.

Lo que hace y lo que no pretende ser.

La promesa es técnica y concreta: operar mejor SAGE50 desde consola, sin vender una suite que el producto no es.

Sí encaja cuando necesitás

  • consultas rápidas de soporte o diagnóstico;
  • exportaciones puntuales para revisión o integración;
  • scripts Python con contexto SAGE50 inicializado;
  • mantenimientos técnicos repetibles.

No es

  • un reemplazo completo de SSMS;
  • un ETL o migrador de esquemas;
  • una interfaz web o API REST;
  • una solución BI visual para usuario final.

Arranque rápido

Descargá el ZIP de release, extraé en `C:\S50Info\`, completá `config.ini` con servidor, credenciales, driver y comunes, y verificá la conexión.

s50info.exe info
s50info sql "SELECT * FROM #clientes" --sqlyear @
s50info export "SELECT * FROM #clientes" --formato xlsx --output clientes

S50Info es una herramienta técnica gratuita para SAGE50. Para informes visuales y plantillas de negocio, la documentación recomienda Sage50BI.
