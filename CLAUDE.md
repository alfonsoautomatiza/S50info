# CLAUDE.md

Este repositorio centraliza todas las instrucciones de trabajo en:

```text
agent.md
```

## Norma obligatoria

- Lee siempre `agent.md` antes de trabajar en este proyecto.
- Usa `agent.md` como única fuente de verdad para normas, contexto, decisiones y preferencias del proyecto.
- Si necesitas añadir, corregir o actualizar instrucciones del agente, hazlo en `agent.md`.
- No modifiques `CLAUDE.md` para añadir normas nuevas del proyecto.
- Este archivo debe mantenerse solo como puente/redirección hacia `agent.md`.

## Motivo

Evitar instrucciones duplicadas o contradictorias entre ficheros. `CLAUDE.md` existe únicamente para compatibilidad con herramientas que lo leen automáticamente.
