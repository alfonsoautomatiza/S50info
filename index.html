    S50Info: control operativo real para equipos de Sage50¶

    S50Info es una herramienta CLI gratuita para Sage50 enfocada en soporte tecnico, consultas SQL de lectura, exportacion de datos y ejecucion de scripts Python. Si tu equipo necesita resolver incidencias mas rapido y repetir tareas con menos riesgo, esta documentacion te guia paso a paso.

    Empezar en 5 minutos Ver la guia completa

    Propuesta de valor

    Menos tiempo en tareas manuales y mas consistencia en soporte, control de datos y operativa recurrente.

    Posicionamiento claro

    S50Info esta pensado para equipos tecnicos. Para analitica visual de usuario final, conviene usar una solucion BI especifica.

    Cuando aporta mas

    En incidencias, revisiones de datos, exportaciones periodicas e integraciones de bajo coste operativo.

    Limite funcional

    Este manual se basa en funcionalidades confirmadas por README: lectura SQL, exportacion, scripts Python y utilidades CLI.

    Resultado esperado

    Procesos repetibles, entregables claros y mejor tiempo de respuesta en soporte.

    Valor por perfil de trabajo¶

    - :material-headset: **Soporte tecnico** --- Diagnostica entorno con `info`, valida datos con `sql` y entrega evidencias con `export`. - :material-briefcase-check: **Consultoria** --- Estandariza extracciones para revisiones, cierres y validaciones con negocio. - :material-cog-refresh: **Operaciones** --- Automatiza rutinas con `run` y reduce dependencia de tareas manuales. - :material-connection: **Integraciones** --- Prepara salidas en `csv`, `json`, `xlsx`, `html` o `txt` para procesos externos.

    Mini FAQ para decidir hoy¶

    S50Info encaja en un equipo no tecnico?

    Su encaje principal es tecnico y operativo. Para uso final visual conviene otro tipo de herramienta.

    Se puede usar para exportaciones recurrentes?

    Si. Es uno de los usos mas habituales en soporte e integraciones.

    Puedo arrancar sin cambiar procesos de golpe?

    Si. Empieza por una incidencia o reporte recurrente y escala progresivamente.

    Que validacion minima debo exigir?

    info, una consulta de lectura y una exportacion de prueba.

    Checklist de adopcion inicial¶

    • Validar acceso al entorno Sage50
    • Ejecutar s50info info correctamente
    • Confirmar una consulta SQL de lectura
    • Generar una exportacion de prueba
    • Definir un flujo recurrente por equipo
